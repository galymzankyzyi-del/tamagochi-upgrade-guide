# TAMA.LAB — интерактивная инструкция для автономного Тамагочи

Готовый статический сайт (HTML + CSS + JavaScript), без сборки, зависимостей и сервера.

## Запуск локально

Откройте `index.html` браузером (для полного тестирования через `http://localhost` можно использовать `python -m http.server 8000`).

## Публикация на Render

1. Загрузите содержимое этой папки в **корень репозитория GitHub**.
2. На [render.com](https://render.com/) выберите **New → Static Site**.
3. Подключите GitHub-репозиторий.
4. **Build command:** оставьте пустым (или `echo ready`, если Render требует команду).
5. **Publish directory:** `.` (точка — текущий каталог).
6. Нажмите **Deploy Static Site**.

Если файлы находятся в папке `tamago-guide` внутри репозитория, укажите её в Publish directory, а не `.`.

## Содержание

- `index.html` — структура сайта и нарисованная SVG-схема
- `styles.css` — адаптивный тёмно-синий дизайн, анимация проводов
- `script.js` — навигация, чек-листы, сохранение прогресса (`localStorage`)
- `favicon.svg` — иконка сайта

## Важное предупреждение

Сайт носит учебный характер, схема электрическая **условная**. Перед установкой 18650 обязательны проверка полярности и отсутствия короткого замыкания прибором, а также подтверждение подходящей платы защиты Li-ion. **Не подключать батарею вслепую.**
